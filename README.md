# «Тук-тук» (TukTuk) 🔮

Нативний помічник для **MacBook Notch (чілки)**, створений спеціально для **Google Antigravity** на чистому Swift & SwiftUI.

Репозиторій повністю очищено від стороннього коду та зайвих API-ключів. Головна мета — забезпечити автентичний візуальний досвід розгортання шторки з чілки, налаштування та бездоганну синхронізацію інтерактивних запитань Antigravity.

---

## ✨ Особливості «Тук-тук»

1. **Автентична виїзна шторка (Hover Drawer):**
   * При наведенні курсору миші на чілку плавно опускається панель керування з маскотом Mochi у чарівному капелюсі.
   * Кнопки швидкого доступу: ⚙️ Налаштування, 🔊 Керування звуком, ⚡️ Тестовий запит, фокус на Antigravity.
2. **Повноцінне вікно налаштувань (⌘,):**
   * **Основні:** вмикання/вимикання звуку, повзунок гучності, таймаут автозакриття карток (10с, 30с, 60с, 120с).
   * **Antigravity:** моніторинг активного сокета, підтримка всіх сесій/ID, інструкція для друзів.
   * **Сповіщення:** перемикачі для Telegram, WhatsApp, Viber, пошти та веб-сповіщень браузера.
   * **Про програму:** інформація про версію та автора.
3. **Одночасне відображення («і там, і тут»):**
   * Коли Antigravity ставить запитання (`ask_question`), красива картка розгортається з чілки MacBook **одночасно** з модальним вікном Antigravity IDE.
4. **Двосторонній вибір без затримок:**
   * **Якщо ви клікнули варіант у чілці:** нативний додаток автоматично передає ваш вибір в Antigravity та підтверджує його.
   * **Якщо ви вибрали варіант у вікні IDE:** картка в чілці плавно та елегантно згортається.
5. **Мультисесійність та підтримка будь-яких пристроїв:**
   * Працює автоматично з усіма проектами та ID Antigravity на вашому Mac.
   * Друг може встановити «Тук-тук» на свій Mac однією командою!

## ⚡ Швидке встановлення (1 команда)

На будь-якому Mac, де встановлено Antigravity, відкрийте Термінал і виконайте:

```bash
curl -sSL https://raw.githubusercontent.com/ruslanower/coucou-antigravity/main/install.sh | bash
```

### Що робить інсталятор:
- 🛠 Збирає нативний додаток `TukTuk.app` на чистому Swift/SwiftUI.
- 📦 Встановлює програму в `/Applications/TukTuk.app`.
- 🌉 Встановлює міст `nb-hook` та `nb-hook.py`.
- 🔗 Налаштовує хуки життєвого циклу в `~/.gemini/config/hooks.json`.
- 🚀 Автоматично запускає «Тук-тук».

## 🔐 Дозволи macOS

Для автоматичного підтвердження вибору з чілки:
- **Спеціальні можливості (Accessibility):**  
  Переконайтеся, що **Тук-тук** або ваш термінал має дозвіл керувати вибором клавіш у *Системні параметри → Приватність і безпека → Спеціальні можливості*.

## 📁 Структура проєкту

* **`Sources/TukTuk/`** — нативний Swift/SwiftUI додаток:
  * `Main.swift` — життєвий цикл NSApplication / Menu Bar.
  * `NotchWindow.swift` — плаваюче вікно над чілкою з підтримкою hover-шторки.
  * `NotchView.swift` — інтерфейс чілки, Mochi у капелюсі, картки запитань.
  * `SettingsView.swift` — вікно налаштувань з 4 вкладками.
  * `AppState.swift` — керування станом, звуками та налаштуваннями UserDefaults.
  * `SocketServer.swift` — локальний Unix-сокет для звʼязку з Antigravity.
  * `AntigravityBridge.swift` — автовибір та підтвердження варіантів.
  * `SoundEffect.swift` — звуковий супровід з контролем гучності.
* **`install.sh`** — автоматичний інсталятор для macOS.
* **`nb-hook.py`** — високошвидкісний міст для хуків Antigravity.
* **`hooks.json`** — конфігурація хуків життєвого циклу Antigravity.
