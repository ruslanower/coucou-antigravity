# Coucou for Google Antigravity 🪄

Розширена інтеграція компаньйона **Coucou (Mochi)** з AI-агентом **Google Antigravity** для macOS.

Цей репозиторій містить автоматизований інсталятор та модифікований релей-міст, який адаптує Coucou для повноцінної роботи з Antigravity, включаючи дублювання запитань та карток дозволів прямо в чілку (Mac Notch / Dynamic Island).

---

## ⚡️ Швидке встановлення для колег (в 1 рядок)

Відкрийте **Термінал** на Mac і виконайте команду:

```bash
curl -sSL https://raw.githubusercontent.com/ruslanower/coucou-antigravity/main/install.sh | bash
```

### Що робить цей інсталятор:
1. 📥 Завантажує та встановлює офіційний реліз **Coucou.app** (v0.3.0) у `/Applications`.
2. 🔓 Знімає карантинні атрибути Gatekeeper (`xattr -cr`).
3. 🌉 Встановлює вдосконалений міст `nb-hook` та `nb-hook.py`, який конвертує запити Antigravity у формат карток Coucou.
4. ⚙️ Вмикає показ карток у чілці (`terminalCardsEnabled`) та закріплює віджет Antigravity як головний.
5. 🔗 Підключає хуки життєвого циклу Antigravity (`~/.gemini/config/hooks.json`).
6. 🚀 Запускає Coucou та відкриває розділ «Спеціальні можливості» (Accessibility) для швидкого надання доступу.

---

## 🎯 Можливості інтеграції

* **Моніторинг у реальному часі:** Mochi в чілці показує поточний крок Antigravity (читання файлів `view_file`, команди `run_command`, веб-пошук тощо).
* **Дублювання запитань:** Коли Antigravity ставить запитання з варіантами відповідей (`ask_question`), картка з варіантами відкривається одночасно **і в чілці, і у вікні чату Antigravity**.
* **Картки підтвердження прав:** Запити на дозвіл виконання команд дублюються в чілку.
* **Звуковий супровід:** Фірмові звуки завершення задачі (`finish`), помилки (`error`) чи вичерпання лімітів.
* **Автоматичне закриття:** Після вибору варіанта або завершення кроку в IDE картка в чілці автоматично закривається.

---

## 🛠 Ручне налаштування дозволів macOS

Після встановлення macOS запитає дозвіл на керування:
1. Перейдіть у **Системні параметри → Приватність і безпека → Спеціальні можливості (Accessibility)**.
2. Увімкніть перемикач навпроти **Coucou**.

---

## 🗑 Видалення (якщо потрібно)

Щоб відключити хуки та повернутися до стандартного стану:
```bash
rm -f ~/.gemini/config/hooks.json
pkill -x Coucou || true
```
