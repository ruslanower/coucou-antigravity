# Coucou + Google Antigravity 🚀

Автоматизований міст для інтеграції **[Coucou](https://github.com/Louis-CFM/coucou)** (macOS notch companion з маскотом Mochi) та **Google Antigravity**.

Репозиторій створений суто для Antigravity без зайвих сторонніх агентів. Головна мета — забезпечити надійне паралельне дублювання сповіщень і автоматичну передачу відповідей між чілкою та середовищем розробки.

---

## ✨ Як це працює

1. **Паралельне відображення («і там, і тут»):**
   * Коли Antigravity звертається до вас із запитанням (`ask_question`) або запитом дозволу на команду (`run_command`), запит зʼявляється **одночасно**:
     * У верхній чілці macOS (разом із Mochi та клікабельними варіантами).
     * У нативному модальному вікні чату Antigravity IDE.
2. **Двосторонній вибір:**
   * **Якщо ви клікнули варіант у чілці Coucou** — міст автоматично вибирає цей варіант у модальному вікні Antigravity та підтверджує його. Вам не потрібно робити подвійний клік у чаті!
   * **Якщо ви клікнули варіант у вікні чату** — чілка Coucou одразу фіксує відповідь і закриває картку.

---

## ⚡ Швидке встановлення (1 команда)

На будь-якому Mac, де встановлено Antigravity, відкрийте Термінал і виконайте:

```bash
curl -sSL https://raw.githubusercontent.com/ruslanower/coucou-antigravity/main/install.sh | bash
```

### Що робить інсталятор:
- ⬇️ Завантажує та встановлює офіційний реліз `Coucou.app` (v0.3.0).
- 🔓 Знімає карантинні обмеження Gatekeeper (`xattr -cr`).
- 🌉 Встановлює оптимізований міст `nb-hook` та `nb-hook.py`.
- ⚙️ Активує віджет Antigravity та показ інтерактивних карток у чілці.
- 🔗 Прописує хуки Antigravity у `~/.gemini/config/hooks.json`.
- 🚀 Запускає Coucou та відкриває налаштування Спеціальних можливостей.

---

## 🔐 Необхідні дозволи macOS

Під час першого запуску потрібно надати два дозволи:
1. **Спеціальні можливості (Accessibility):**  
   *Інсталятор сам відкриє це вікно.* Увімкніть перемикач навпроти **Coucou**, щоб програма могла передавати вибір між чілкою та IDE.
2. **Системні сповіщення (Notifications):**  
   Коли macOS покаже запит «Coucou wants to send you notifications» — натисніть **«Дозволити» (Allow)**.

---

## 📁 Структура репозиторію

* **`install.sh`** — автоматичний інсталятор для macOS.
* **`nb-hook.py`** — ядро мосту: нормалізація подій, сокет Coucou та передача вибору між чілкою та IDE.
* **`nb-hook`** — швидкий шелл-ранер для запуску мосту.
* **`hooks.json`** — конфігурація хуків життєвого циклу Antigravity (`PreToolUse`, `PostToolUse`, `Stop`).
