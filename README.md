# «Rango» 🦎

Нативний ШІ-помічник для **MacBook Notch (чілки)**, створений спеціально для **Google Antigravity** на чистому Swift & SwiftUI.

Головний герой додатку — харизматичний хамелеон **Rango**! Додаток інтегрований у чілку MacBook, аналізує ваші проєкти в Antigravity та генерує ідеї нових застосунків з можливістю запустити їх розробку в один клік.

---

## ✨ Особливості «Rango»

1. **Хамелеон Rango в чілці та шторці (Hover Drawer):**
   * При наведенні курсору миші на чілку плавно опускається панель керування з живим персонажем Rango.
   * Кнопки швидкого доступу: ⚙️ Налаштування, 🔊 Керування звуком, фокус на Antigravity, генерація ідей.
2. **Динамічний генератор ідей на основі проєктів Antigravity:**
   * Сканує активні проєкти користувача в `~/.gemini/config/projects/`.
   * Генерує цільові ідеї застосунків під конкретні проєкти (фітнес, YouTube-автоматизація, документи, їжа, цілі тощо).
   * Знаходить неочевидні міжпроєктні синергії (наприклад, синергія коворкінгу та генератора договорів).
   * Якщо проєктів немає — генерує свіжі конкурентоспроможні ідеї для стартапів.
3. **Кнопка «Втілити ідею 🚀» в 1 клік:**
   * Автоматично розгортає Antigravity, відкриває новий чат (**+ New Conversation**), фокусує поле введення та надсилає детальний бриф для розробки MVP.
4. **Повноцінне вікно налаштувань (⌘,):**
   * **Основні:** вмикання/вимикання звуку Rango, повзунок гучності, автозакриття.
   * **Antigravity:** моніторинг активного сокета, підтримка всіх сесій/ID, встановлення для друзів.
   * **Сповіщення:** перемикачі для Telegram, WhatsApp, Viber, пошти та веб-сповіщень браузера.
   * **Про програму:** інформація про Rango та автора.
5. **Двостороння синхронізація запитань:**
   * Коли Antigravity ставить запитання (`ask_question`), картка виїжджає з чілки MacBook **одночасно** з модальним вікном Antigravity IDE.
   * Клік по варіанту в чілці автоматично обирає відповідь у сесії Antigravity!

## ⚡ Швидке встановлення (1 команда)

На будь-якому Mac, де встановлено Antigravity, відкрийте Термінал і виконайте:

```bash
curl -sSL https://raw.githubusercontent.com/ruslanower/rango/main/install.sh | bash
```

### Що робить інсталятор:
- 🛠 Збирає нативний додаток `Rango.app` на чистому Swift/SwiftUI.
- 📦 Встановлює програму в `/Applications/Rango.app` з офіційною іконкою Rango.
- 🌉 Встановлює міст `nb-hook` та `nb-hook.py`.
- 🔗 Налаштовує хуки життєвого циклу в `~/.gemini/config/hooks.json`.
- 🚀 Автоматично запускає «Rango».

## 🔐 Дозволи macOS

Для автоматичного підтвердження вибору з чілки:
- **Спеціальні можливості (Accessibility):**  
  Переконайтеся, що **Rango** або ваш термінал має дозвіл у *Системні параметри → Приватність і безпека → Спеціальні можливості*.

## 📁 Структура проєкту

* **`Sources/Rango/`** — нативний Swift/SwiftUI додаток:
  * `Main.swift` — життєвий цикл NSApplication / Menu Bar (🦎).
  * `NotchWindow.swift` — плаваюче вікно над чілкою з підтримкою hover-шторки.
  * `NotchView.swift` — інтерфейс чілки, хамелеон Rango, картки ідей та запитань.
  * `ProjectIdeaGenerator.swift` — динамічний аналізатор проєктів Antigravity та генератор ідей.
  * `AntigravityBridge.swift` — міст автоматизації фокусу, нового чату та відправки промптів.
  * `AppState.swift` — реактивний стан додатку (меню, запитання, налаштування).
  * `SettingsView.swift` — налаштування каналів сповіщень та звуку.
  * `SocketServer.swift` — Unix Domain Socket сервер зв'язку з хуками (`/tmp/rango.sock`).
  * `SoundEffect.swift` — аудіоефекти кліків та переходів.
* **`Resources/`** — асети:
  * `rango.png` — офіційний арт хамелеона Rango.
  * `AppIcon.icns` — фірмова macOS іконка додатку Rango.
  * `sounds/` — набір звукових ефектів.
* **`nb-hook.py`** & **`nb-hook`** — хуки розширення Antigravity.
* **`hooks.json`** — конфігурація хуків Antigravity.
* **`install.sh`** — скрипт збірки та встановлення в 1 клік.
