# Coucou Antigravity 🚀

Нативний помічник для **MacBook Notch (чілки)**, створений спеціально для **Google Antigravity** на чистому Swift & SwiftUI.

Репозиторій повністю очищено від стороннього коду (Claude, Copilot, Hermes тощо) та зайвих API-ключів. Головна мета — забезпечити бездоганну роботу інтерактивних карток запитань у чілці macOS паралельно з діалоговим вікном Antigravity IDE.

---

## ✨ Як це працює

1. **Одночасне відображення («і там, і тут»):**
   * Коли Antigravity ставить запитання (`ask_question`), красива картка розгортається з чілки MacBook **одночасно** з модальним вікном Antigravity IDE.
2. **Двосторонній вибір без затримок:**
   * **Якщо ви клікнули варіант у чілці:** нативний додаток автоматично передає ваш вибір в Antigravity та підтверджує його.
   * **Якщо ви вибрали варіант у вікні IDE:** картка в чілці плавно та елегантно згортається.
3. **Жодних сторонніх API-ключів або тайм-аутів:**
   * Додаток повністю нативний і автономний — жодних запитів про "API key missing", тайм-аутів закриття чи конфліктів черги.

## ⚡ Швидке встановлення (1 команда)

На будь-якому Mac, де встановлено Antigravity, відкрийте Термінал і виконайте:

```bash
curl -sSL https://raw.githubusercontent.com/ruslanower/coucou-antigravity/main/install.sh | bash
```

### Що робить інсталятор:
- 🛠 Збирає нативний додаток `CoucouAntigravity.app` на чистому Swift/SwiftUI.
- 📦 Встановлює програму в `/Applications/CoucouAntigravity.app`.
- 🌉 Встановлює міст `nb-hook` та `nb-hook.py`.
- 🔗 Налаштовує хуки життєвого циклу в `~/.gemini/config/hooks.json`.
- 🚀 Автоматично запускає помічника в чілці.

Для автоматичного підтвердження вибору з чілки:

## 📁 Структура проєкту

* **`Sources/CoucouAntigravity/`** — нативний Swift/SwiftUI додаток:
  * `Main.swift` — життєвий цикл NSApplication / Menu Bar.
  * `NotchWindow.swift` — плаваюче вікно над фізичною чілкою MacBook.
  * `NotchView.swift` — інтерфейс Mochi та карток запитань.
  * `SocketServer.swift` — локальний Unix-сокет для звʼязку з Antigravity.
  * `AntigravityBridge.swift` — автовибір та підтвердження варіантів.
  * `SoundEffect.swift` — звуковий супровід.
* **`install.sh`** — автоматичний інсталятор для macOS.
* **`nb-hook.py`** — надшвидкий міст для хуків Antigravity.
* **`hooks.json`** — конфігурація хуків життєвого циклу Antigravity.
